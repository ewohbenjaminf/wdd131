Website Planning Document

A digital guide to discovering Nigeria

This plan establishes the visual identity, purpose, audience, content, and homepage layout for the WDD 131 final project.

1. Site Name

Discover Nigeria

The name clearly communicates the purpose of the website: helping visitors discover Nigeria's culture, food, destinations, traditions, and interesting facts. It is short, memorable, and broad enough to support several related content areas.

Proposed domain: discover-nigeria.example

The domain shown above is only a planning example; purchasing a domain is not required for this course.

2. Site Purpose

Discover Nigeria will provide clear, engaging information about Nigeria for people who want to learn about the country's culture, traditional foods, places to visit, festivals, cities, traditions, and interesting facts. The website will combine informative content with responsive design and JavaScript-driven interaction.

  • Introduce visitors to Nigerian culture and traditions.
  • Highlight Nigerian foods and explain their cultural significance.
  • Present interesting destinations and places to visit.
  • Share festivals, customs, and useful facts about Nigeria.
  • Provide an interactive experience using JavaScript.

3. Target Audience

The primary audience includes students, travelers, tourists, researchers, Nigerians living abroad, and anyone interested in learning about Nigeria. The design will use clear headings, readable text, strong visual hierarchy, responsive layouts, and simple navigation.

5. Color Scheme

The color palette combines Nigerian-inspired green with a warm gold accent. White and charcoal provide clean backgrounds and readable text.

Forest Green

#006B3C

Primary color for header elements, headings, navigation accents, and buttons.

Warm Gold

#F4B400

Accent color for highlights, labels, icons, borders, and calls to action.

Charcoal

#1F2937

Primary body text and strong contrast elements.

White

#FFFFFF

Main page background and text on dark green sections.

6. Typography

Poppins

Headings and branding

Poppins 600/700 will be used for page titles, section headings, navigation branding, and important labels.

Open Sans

Body text

Open Sans 400/600/700 will be used for paragraphs, lists, navigation text, labels, and supporting information.

7. Planned Website Content

The final project will contain at least three pages with consistent navigation and visual styling.

Home — index.html

Introduction to Nigeria, featured destinations, food, culture, and navigation to the main content.

Food — food.html

Traditional Nigerian dishes, descriptions, regions, and an interactive food-filtering experience.

Places — places.html

Selected Nigerian destinations such as Lagos, Abuja, Obudu, and Yankari with useful descriptions.

Culture — culture.html

Festivals, traditions, cultural information, and interesting facts about Nigeria.

References — references.html

Sources for borrowed images and text. This page will be linked from the footer.

8. Planned JavaScript Features

  • Use multiple functions to organize interactive behavior.
  • Select and modify DOM elements.
  • Listen for user events such as clicks or selections.
  • Use conditional branching to respond to user choices.
  • Use objects, arrays, and array methods to manage content.
  • Use template literals when generating output strings.
  • Use localStorage to save a user preference or interaction.

10. Development and Testing Plan

  • Use semantic HTML and validate the document with the W3C HTML validator.
  • Validate CSS with the W3C CSS validator and remove errors.
  • Optimize images and use lazy loading where appropriate.
  • Test responsive layouts on mobile and larger screens.
  • Use DevTools to check JavaScript runtime errors.
  • Use Lighthouse for Performance, Accessibility, Best Practices, and SEO on mobile and desktop.
  • Check color contrast and correct spelling and grammar before submission.
